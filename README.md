# AURA CLINIC // Clinical Care & Healthcare Appointment System

A healthcare appointment and telehealth consultation management system built with React, Vite, Tailwind CSS, and Zustand, backed by a simulated Supabase/PostgreSQL relational schema.

## 🩺 Key Features
- **Physician Directory & Specialty Search**: Search and filter board-certified specialists with real-time fee and availability data.
- **Appointment Scheduling & Rescheduling**: Dual-mode booking (Virtual Telehealth vs In-Clinic Visit) with instant rescheduling and cancellation handling.
- **Live Telehealth Video Consultation Room**: Encrypted virtual consultation room simulation with camera/microphone controls.
- **Patient Record Vault**: Centralized medical record repository for lab panels, medication histories, and imaging reports.
- **Doctor Schedule Optimizer**: AI-assisted slot buffer scheduling, queue compression, and zero-collision booking.
- **Clinic Administration & Wait-Time Intelligence**: Real-time throughput metrics, average wait-time tracking, room occupancy telemetry, and operational signals.

## 🚀 Quickstart
```bash
npm install
npm run dev
```
